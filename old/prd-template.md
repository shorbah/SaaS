## 4. قصص المستخدم (User Stories)

> صغ كل ميزة بهذا الشكل: "بصفتي [دور]، أريد [فعل]، حتى أتمكن من [هدف]."

```
بصفتي صاحب محل، أريد مشاهدة جميع الطلبات الحالية،
حتى أتمكن من متابعة حالة المطبخ في الوقت الفعلي.

بصفتي موظف، أريد تحديث حالة الطلب (جاري/مكتمل)،
حتى يعرف الزبون متى طلبه جاهز.

بصفتي زبون، أريد تصفح القائمة وإضافة طلب،
حتى لا أحتاج للانتظار للتحدث مع الموظف.
```

## 5. نموذج البيانات (Data Model)

> الجداول الرئيسية وعلاقاتها فقط — التفاصيل تُحدَّد مع Prisma

```
[اسم الجدول الأول]
├── id
├── [حقل 1]
├── [حقل 2]
└── [علاقة بجدول آخر]

[اسم الجدول الثاني]
├── id
├── [حقل 1]
└── [علاقة: userId → Users]
```

**مثال — نظام طلبات:**
```
Users
├── id, name, email, role
└── → Orders (one to many)

Orders
├── id, status, totalPrice, createdAt
├── → userId (FK)
└── → OrderItems (one to many)

OrderItems
├── id, quantity, unitPrice
├── → orderId (FK)
└── → productId (FK)

Products
├── id, name, price, isAvailable
└── → Category (many to one)
```
